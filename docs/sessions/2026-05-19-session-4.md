### Discoveries / JIT items surfaced this session

1. **AGP 9.0 `kotlin.android` plugin removal.** AGP 9.0 has built-in Kotlin support; `org.jetbrains.kotlin.android` plugin is deprecated. Removed from `kiln.android.app` convention + commented in root build.gradle.kts. Referenced at https://kotl.in/gradle/agp-built-in-kotlin.

2. **AGP 9.0 `com.android.kotlin.multiplatform.library` requirement.** AGP 9.0 breaking change: `com.android.library` plugin is incompatible with `org.jetbrains.kotlin.multiplatform` plugin. Swapped in `kiln.kmp.library` convention. New DSL pattern: `kotlin { androidLibrary { compileSdk; minSdk; namespace } }` replaces separate `android { ... }` block. Matches Slack circuit's `agp-kmp` plugin pin.

3. **Gradle 9.x strict `include()` directory requirement.** Older Gradle was lenient about `include(":foo")` when `./foo/` doesn't exist. Gradle 9.x requires the directory to exist at evaluation time. Module phantom dirs created with `.gitkeep` placeholders (removed once real `build.gradle.kts` files landed at Task #7).

4. **`jvm("desktop")` source set rename.** Compose-MP idiom `jvm("desktop")` makes JVM source sets `desktopMain`/`desktopTest`, not `jvmMain`/`jvmTest`. Fixed in `:audio:playback` and `:data:library` after Task #8 dry-run flagged "Unused Kotlin Source Sets" warning.

5. **kmpalette artifact NOT on Maven Central** — full Item 3 vetting log addendum at `docs/decisions/2026-05-18-library-vetting.md` "Item 3 addendum: kmpalette publication gap" section. Resolution deferred per Item 3's existing soft-lock cascade (revisit at Phase 2a Flight A) — three paths queued (JitPack / file issue / roll-our-own). For now, dep commented out in `:ui:theme/build.gradle.kts` with explanatory note.
