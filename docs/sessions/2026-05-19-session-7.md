## Discoveries (worth carrying forward)

1. **SQLDelight type-narrowing on `IS NULL` (rather than `IS NOT NULL`) does NOT narrow the row class.** Session 6 discovered `WHERE last_played_ms IS NOT NULL` generates a custom `SelectRecentlyPlayed` class. Conversely, `WHERE deleted_at_ms IS NULL` (used in `selectByAlbum`, `selectTracksOfPlaylist`, the new `selectAllForFtsRebuild`, etc.) does NOT narrow — the column was already nullable, and "always null" is a subset of nullable. Track rows return as `Track`; no extra mapper needed.

2. **`@Suppress` cannot be applied to a constructor-call argument label.** `MediaCols(@Suppress("DEPRECATION") data = cursor.getColumnIndex(...), ...)` is a parse error ("Only expressions are allowed in this context"). Move the suppress to the enclosing function or class — `@Suppress("DEPRECATION") companion object { ... }` works.

3. **MediaStore.Audio.Media DATE_MODIFIED is seconds-since-epoch, NOT milliseconds.** Multiplying by 1000L bridges to the schema's millisecond timestamps. Filesystem mtime via `Files.getLastModifiedTime().toMillis()` is already ms.

4. **MediaStore's TRACK column encodes disc number when present** — values > 1000 are typically "1NNN"-form (disc 1, track NNN). Modulo 1000 to extract just the track number. Disc number is otherwise not directly available via MediaStore.Audio.Media.

5. **MediaStore artist/album use the literal `"<unknown>"` placeholder** (angle brackets included) for missing metadata. Filter these out alongside blank-string checks; otherwise the library accumulates a "&lt;unknown&gt;" artist that wins all sort-name comparisons.

6. **jaudiotagger's `header.bitRateAsNumber` returns Long (not int).** The other format methods (`sampleRateAsNumber`, `bitsPerSample`, `trackLength`) return Int. Avoid blanket `.toLong()` — it warns on `bitRateAsNumber`. Different field types is a jaudiotagger oddity.

7. **`@JvmInline` value-class `SourceId(val value: String)` parses cleanly with prefix-namespaced strings.** Tracks remain bare numeric ItemIds; Albums/Artists/Playlists prefix with `"album:"/"artist:"/"playlist:"` for disambiguation in mixed-kind MediaItem flows. `getPlayable` parses the prefix → returns `ItemNotFound` for any non-numeric (container) ItemId.

8. **`MediaSession.Builder(context, exo).build()` works at construction time** — no extra Service binding required for the session token to be valid. Full MediaSessionService wrapper (lockscreen + Auto + BT controls) is a separate file with its own AndroidManifest entry; deferred until a UI surface needs system controls.

9. **`Dispatchers.Main.immediate` is the right context for all ExoPlayer method calls.** ExoPlayer enforces single-thread access via its application looper (default = `Looper.getMainLooper()`). Using `.immediate` avoids unnecessary post when already on main.
