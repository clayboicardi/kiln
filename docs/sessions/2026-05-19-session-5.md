### Discoveries this session

1. **🔥 Spec §2 Item 1 minSdk hard-lock revisit 21 → 23.** Compose Multiplatform 1.11.0's `components-resources-android` requires minSdk ≥ 23. Vetting log Item 1 addendum captures full discovery + decision rationale. Clay approved 2026-05-19. Ripple: spec, CLAUDE.md, libs.versions.toml, 2 conventions, vetting log. Risk-playbook R4 (originally framed as a Coil 3.x risk) implicitly resolved by this revisit.

2. **`bundles.compose-mp-common` needed in app modules.** Project deps from `:ui:*` expose Compose libs as `implementation` (not `api`) per convention design, so `:app-android` and `:app-desktop` must add the bundle directly to access Compose-MP types in their source code.

3. **`:app-desktop` also needs `compose.desktop.currentOs`.** Canonical Compose Desktop pattern from JB docs — provides platform-specific Skia + window toolkit jars. Combined with `bundles.compose-mp-common` for the foundation/material3/ui types.

4. **GitHub-hosted runners support our stack out-of-the-box.** ubuntu-latest has Android SDK + android-36 platform pre-installed (no explicit `android-actions/setup-android` step needed). windows-latest builds `:app-desktop:assemble` cleanly without WiX (since not running `packageDistributionForCurrentOS` yet).
