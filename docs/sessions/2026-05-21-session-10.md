## Discoveries (worth carrying forward to cumulative gotcha list)

3 new gotchas this session — candidates for `CLAUDE.md` Build/Dep Gotchas section:

1. **arrow.core must be `api`, not `implementation`, in any module whose public surface uses `Either<L, R>`.** :data:library carried arrow.core as `implementation`, which works as long as no consumer needs to pattern-match Either.Right/Left. The moment :app-android or :app-desktop tried to `when (result) { is Either.Right -> ...; is Either.Left -> ... }`, the build broke with "Unresolved reference 'arrow'." Promote to `api` whenever Either crosses a module boundary.

2. **`BrowseScope.AllTracks` is a `data class` with default params**, NOT a `data object` — must be instantiated with `BrowseScope.AllTracks()` (with parens). Easy mistake when copy-pasting from a handoff that uses object-style references.

3. **For Compose Multiplatform, the Surface fillMaxSize + Column padding pattern works on both Android and Desktop without target-specific code.** No Android-only `androidx.compose.material3.*` vs Desktop-specific imports needed; the bundled compose-mp common artifact covers both. Confirmed at H7 wire-up.
